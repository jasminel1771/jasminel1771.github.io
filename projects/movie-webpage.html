Movie Webpage Project

Context

In this project, Mr. Mueller assigned us a movie webpage project where we had to work with a partner after learning the basics of HTML and CSS. We were given the freedom to choose our own movie's storyline, style, and genre. My partner and I decided to create our own original movie called "The Tunneler." We came up with the plot ourselves and used HTML and CSS to create a webpage that introduces our movie.

Content

My partner and I came up with an original movie called "The Tunneler", which is about a mysterious entity living in the sewege tunnels underneath Lower Manhattan. The entity begins causing problems throughout New York City, and the main character, James Rodney, discovers that he has the ability to see beneath the streets and must find a way to stop it. We also created a sequel to our movie for extra credit. For the project requirements, we needed to create both an HTML and CSS webpage, along with a planning page. In HTML, we had to include headings, paragraphs, divs, spans, Google Fonts that we had not used in class, and input and submit elements. For CSS, we needed to use headings, elements, class, and ID selectors, and margins. We also had to include two original images in our webpage. This project allowed us to use the HTML and CSS skills we had learned while developing our own movie idea.

Reflection

One challenge my partner and I faced was communication. We were both naturally quiet and introverted, so we initially thought we could complete most of the work on our own. However, we eventually realized that doing everything by ourselves was difficult, especially since we needed to work together to create one complete project. Another challenge I faced was learning how to use the linear-gradient property in CSS. I asked my partner if he knew how to use it, but he wasn't quite sure either. We decided to search online and found a website called W3Schools, which provided us with a tutorial that helped us understand how to use it. One thing that helped us stay organized was our planning page. We were able to divide our responsibilites easily by writing down the tasks and putting our names next to the ones we were assigned. This made it easier to keep track of our progress and understand what each person needed to complete.

My biggest takeaway from this project is that communication is really important when working with someone else. Without communication, we would have been lost about what to do, how to complete certain tasks, and how to move forward with the project. I also wouldn't have known what my partner liked or wanted to include, which could have resulted in a project that neither of us was satisfied with. Overall, I learned that teamwork isn't just about dividing the work but also sharing ideas, asking questions, and helping each other when we get stuck.

Next Steps

For my next steps, I want to continue improving my HTML and CSS skills by experimenting with more properties and learning how to use them properly. I also want to become more comfortable communicating with my partner instead of assuming that I can complete everything independently.

If we were given another project like this, I would try to share ideas earlier, ask questions when I am confused, and make sure we both agree on the direction of the project.
